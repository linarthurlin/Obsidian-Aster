# 獨立安裝

從本 repo Releases 下載 knowledge-agent-plugin-<version>.zip，解壓到 <vault>/.obsidian/plugins/knowledge-agent/。重新載入 Obsidian，再由使用者啟用外掛。

此 repo 不安裝其他元件。Installer 只複製 main.js、manifest.json 與 styles.css，不改筆記、data.json、外觀選擇或啟用清單。舊檔備份在本地 .local/backups。先用獨立測試庫確認。

元件與 BRAT 遷移見 [REPOSITORY-SPLIT.md](REPOSITORY-SPLIT.md)。
