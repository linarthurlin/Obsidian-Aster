# Aster 獨立安裝

從本 repo Releases 下載 aster-plugin-<version>.zip，解壓到 <vault>/.obsidian/plugins/knowledge-agent/。重新載入 Obsidian，再由使用者啟用 Aster。

manifest ID 和 plugin folder 保留 `knowledge-agent`，以支援現有安裝更新和設定相容。Installer 只複製 main.js、manifest.json 與 styles.css，不改筆記、data.json、外觀選擇或啟用清單。此 repo 不安裝 Halo Theme 或 Orbit。

元件與 BRAT 遷移背景見 [REPOSITORY-SPLIT.md](REPOSITORY-SPLIT.md)。
